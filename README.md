# ⚙️ Create Resource Pack

Welcome to my Create-style Minecraft resource pack!

## 📖 About

This is a Minecraft resource pack inspired by the visual style of the Create mod.

I made this project just for fun! I tried to recreate the Create mod's style, but I didn't have enough time to finish everything.

## ✨ Features

- ⚙️ Create-inspired visual style
- 🎨 Custom Minecraft textures
- 🧱 A fun visual experiment
- 🚧 Work in progress

## 📦 Installation

1. Download the resource pack.
2. Open Minecraft.
3. Go to **Options → Resource Packs**.
4. Click **Open Pack Folder**.
5. Place the resource pack ZIP file inside.
6. Enable the resource pack and enjoy!
